# Coffee Machine Recommender (MCDM 100-Point Model)

เว็บแอปพลิเคชันแนะนำเครื่องชงกาแฟอัจฉริยะ โดยใช้แบบจำลองการตัดสินใจแบบหลายเกณฑ์ (Multi-Criteria Decision Making - MCDM 100 คะแนน) พร้อมคำนวณและแสดงผลเปอร์เซ็นต์ความเหมาะสม (Match Rate 0-100%) และคำอธิบายภาษาไทยแบบเรียลไทม์

## คุณสมบัติเด่น (Features)
- **โหลดข้อมูลอัตโนมัติจากไฟล์ Excel (products.xlsx)** ด้วย SheetJS
- **โมเดลการประเมิน 5 มิติ (100 คะแนน)**:
  1. งบประมาณ (Budget Match - 30 คะแนน)
  2. กำลังผลิตต่อวัน (Capacity Match - 25 คะแนน)
  3. สภาพแวดล้อมการใช้งาน (Usage Segment - 20 คะแนน)
  4. ระบบไฟฟ้า (Electrical Power - 10 คะแนน)
  5. ฟังก์ชันเฉพาะทาง (Feature Fit - 15 คะแนน)
- **Top 3 Recommended Machines**: แสดง 3 เครื่องที่เหมาะสมที่สุดพร้อมแถบวัดคะแนนแต่ละมิติ
- **Side-by-Side Comparison Modal**: เปรียบเทียบสเปกเครื่องแบบเคียงข้างกันได้สูงสุด 3 เครื่อง
- **Export & Summary**: สามารถ Export เป็น JSON หรือคัดลอกรายงานสรุปผลลง Clipboard ได้ทันที
- **Bilingual Support**: รองรับทั้งภาษาไทยและภาษาอังกฤษ

## วิธีการใช้งาน (Getting Started)
1. เปิดไฟล์ index.html บนเบราว์เซอร์ (หรือรันผ่าน Local HTTP Server เช่น Live Server / 
px serve)
2. เลือกงบประมาณ, จำนวนแก้วที่ต้องการต่อวัน, กลุ่มการใช้งาน และระบบไฟฟ้า
3. ระบบจะทำการคำนวณและแสดงผลเครื่องที่เหมาะสมที่สุดให้โดยอัตโนมัติ
